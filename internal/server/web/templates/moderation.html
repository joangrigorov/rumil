How scope and authority work

A REPO rule applies to the repository it was recorded in. An ORG rule applies to every repository in the organization that has nothing more specific to say; a repository rule outranks it when both match. An organization rule can be narrowed to the repository it was proposed in, and a repository rule is not widened from here.

A rule is recorded context, and the repository's own RUMIL.md outranks it. Promoting one to DIRECTIVE puts it above that file for the case it names, and the reviewer says so in its summary when the two conflict. A directive applies to one repository, so an organization-wide rule is recorded for a repository first.
